# Alex Turner - Premium Portfolio

A stunning, fully-featured portfolio website showcasing the **£599 Premium Portfolio** service by WebRise Development.

[Live Demo](https://levmanzhai.github.io/Premium-Portfolio/#)

## 🎯 Project Overview

This is a **client-facing demo** for **Alex Turner**, a fictional Creative Director from London. The site demonstrates exactly what clients receive when purchasing the Premium Portfolio service.

## ✨ Features

### Core Functionality
- ✅ **100% Offline** - No backend, no APIs, works entirely in the browser
- ✅ **localStorage Integration** - Theme preferences and form submissions saved locally
- ✅ **Fully Responsive** - Mobile-first design that looks great on all devices
- ✅ **Dark/Light Mode** - Theme toggle with localStorage persistence
- ✅ **PDF Download** - Generate and download CV using jsPDF

### Pages

1. **Home (/)**
   - 3D animated background with floating geometric shapes
   - Cinematic hero section with smooth animations
   - Animated stats counter (Years Experience, Projects, Clients)
   - Featured work preview
   - CTA sections

2. **Projects (/projects)**
   - Interactive filterable project grid
   - Category-based filtering (All, Branding, Digital Marketing, etc.)
   - Project detail modal
   - Smooth animations and transitions
   - 6 featured projects with full details

3. **About (/about)**
   - Professional timeline
   - Animated skill bars
   - Awards & recognition section
   - Professional photography
   - Download CV button

4. **Contact (/contact)**
   - Lead capture form with validation
   - Form submissions saved to localStorage
   - Contact information display
   - Social media links
   - Success message after submission

5. **Download (/download)**
   - PDF CV generation using jsPDF
   - Professional 2-page CV layout
   - Instant download functionality
   - Feature highlights

## 🛠 Tech Stack

- **React 18** - Latest React with hooks
- **TypeScript** - Type-safe development
- **Tailwind CSS v3** - Utility-first styling
- **Framer Motion** - Smooth animations
- **React Router v6** - Client-side routing
- **React Three Fiber** - 3D graphics (optional)
- **jsPDF** - PDF generation
- **localStorage** - Client-side data persistence
